# Ball Reaction

Predictive movement and hazard-planning system for Roblox dodge or die game.

**Current version:** 1.8.9 betasync5378 (sync family)

## Features

- Multi-threat prediction
- Collision-aware trajectory simulation
- Bounce prediction
- Implicit threat detection
- Hard Safety system
- Jump and double-jump planning
- Dash planning
- Lava platform navigation
- Laser prediction
- Replay debugger
- Debug trace export

## Usage

Enable **Auto Dodge** from the Ball Reaction interface.

The controller automatically tracks nearby hazards, predicts future trajectories and chooses movement actions.

## Debugging

Ball Reaction includes:

- 5-minute replay buffer
- Incident recording
- Threat telemetry
- Collision and bounce diagnostics
- JSON trace export
